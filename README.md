KBC Game is an interactive quiz application developed in Python using Tkinter. The game allows players to select from three categories: Computer, History, and General Knowledge, with questions organized into Easy, Medium, and Hard difficulty levels.

Players answer 10 questions, with prize amounts increasing from Rs. 100 to Rs. 1,000. The application provides immediate feedback for correct and incorrect answers and includes two limited lifelines: Hint and Skip Question. A correct answer advances the player to the next question, while an incorrect answer ends the game and displays the amount won.

The project demonstrates the use of Python dictionaries, lists, functions, global variables, loops, conditional statements, and Tkinter GUI components, including buttons, labels, frames, and message boxes. It provides a simple graphical recreation of a KBC-style quiz game with an interactive dark-themed interface.
